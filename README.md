# 小温工具箱（Android）

**小温工具箱** 是一个**纯本地离线**的 Android 工具箱 App，集合随机工具、影音图像、计算与转换、函数绘图、文本与编码、学习查询与实用工具，共 **77 个工具**。
不联网、不收集、不上传任何数据，所有配置和历史都只保存在用户手机本地。
首页搜索框下方标注：**作者：温景淇**。

> GitHub 仓库名：`xiaowen-toolbox`（GitHub 不支持中文仓库名，中文名“小温工具箱”）
> 仓库地址：https://github.com/jingqiwen/xiaowen-toolbox

## 项目用途

本项目的主要用途是：

1. **把日常零散的小工具整合到一个 App 里**：掷骰子、随机点名、单位换算、进制转换、图片处理、公式查询、背单词等，不用再装一堆应用。
2. **完全离线、保护隐私**：所有功能都在手机本地计算，不联网、不上传数据，适合对隐私敏感的用户。
3. **作为 Android + Jetpack Compose 的学习/参考项目**：代码按“工具注册表 + 单工具页面”的方式组织，新增工具只需写一个 Composable 并注册即可。
4. **个人与朋友之间免费分享使用**：本项目仅供学习、测试和非商业用途，详见 [LICENSE](LICENSE)。

## 技术栈

- Kotlin 2.0.21 + Jetpack Compose（Material 3）
- 单 Activity + Navigation Compose
- 本地存储：SharedPreferences + JSON
- 二维码：ZXing core（本地生成）
- 视频：Media3 Transformer（本地转码/变速）+ 系统 MediaExtractor/Muxer
- 农历：android.icu ChineseCalendar（离线）
- 词库：内置 `app/src/main/assets/vocab_bulk.jsonl`（离线读取）
- minSdk 26（Android 8.0+），targetSdk / compileSdk 36

## 如何运行

> 第一次构建需要联网下载依赖。

1. 用 Android Studio 打开本目录（建议使用已安装的 `D:\Program Files\Android\Android Studio`）。
2. 等待 Gradle Sync 完成。
3. 连接手机（开发者选项 → USB 调试），点击 **Run ▶**；
   或 Device Manager 创建模拟器后运行。

## 词库与公式数据维护

- **背单词词库**：由根目录脚本 `_build_vocab.js` 生成，数据源为 ECDICT（`ecdict.csv`）。
  脚本会按大纲标签与词频重要度补齐到官方规模，并保留 gk/zk 基础词标记以支持“含基础词”模式。

  ```powershell
  $env:CSV_PATH = "C:\path\to\ecdict.csv"
  node _build_vocab.js   # 输出 app/src/main/assets/vocab_bulk.jsonl
  ```

  数据来源：https://github.com/skywind3000/ECDICT （MIT License）。

- **大学教材公式**：按教材拆分为
  `FormulaBooksCalculus.kt`（高数上/下）、`FormulaBooksAlgebra.kt`（线代、概率统计）、
  `FormulaBooksComplex.kt`（复变与积分变换）、`FormulaBooksPhysics.kt`（大物上/下）、
  `FormulaBooksPhysicsLab.kt`（大物实验），由 `FormulaDataBooks.kt` 汇总。

## 已知限制

- Word 转 PDF：当前为 .docx 文本段落转换，图片、表格与复杂排版暂不保留；不支持旧版 .doc。
- 视频：输出统一为 MP4(H.264+AAC)；AVI 及部分特殊编码输入可能失败；**倒放**系统 API 暂不支持，需要引入 FFmpeg 才能实现。
- TIFF：本应用可输出未压缩 TIFF，但 Android 系统无法解码 TIFF 输入，需先用其他应用转成常见格式。
- 词表：考纲词表依据 ECDICT 标签整理，采用“官方规模 + 含基础词补全”两种模式；如与最新版考纲有出入，可自行导入自定义词库补充。
