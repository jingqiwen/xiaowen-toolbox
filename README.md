# 小温工具箱（Android）

**小温工具箱** 是一个 Android 工具箱 App，集合随机工具、影音图像、计算与转换、函数绘图、文本与编码、学习查询与实用工具，共 **78 个工具**。
**仅支持 Android（Android 8.0 / API 26 及以上），不提供 iOS 或网页版。**
默认完全离线可用；联网为**可选功能**（背单词在线补充释义/例句、检查版本更新），可在设置中随时关闭。
所有本地配置、历史与背单词分区都只保存在用户手机本地。
首页搜索框下方标注：**作者：温景淇**。

> GitHub 仓库名：`xiaowen-toolbox`（GitHub 不支持中文仓库名，中文名“小温工具箱”）
> 仓库地址：https://github.com/jingqiwen/xiaowen-toolbox

## 项目用途

本项目的主要用途是：

1. **把日常零散的小工具整合到一个 App 里**：掷骰子、随机点名、单位换算、进制转换、图片处理、公式查询、背单词等，不用再装一堆应用。
2. **默认离线、隐私优先**：绝大多数功能在手机本地计算；联网仅用于可选的在线词典与版本检查，可在设置里关闭，不上传任何个人数据。
3. **作为 Android + Jetpack Compose 的学习/参考项目**：代码按“工具注册表 + 单工具页面”的方式组织，新增工具只需写一个 Composable 并注册即可。
4. **个人与朋友之间免费分享使用**：本项目仅供学习、测试和非商业用途，详见 [LICENSE](LICENSE)。

## 本版修复（v0.12.1）

1. **公式排版重做，解决“位置乱、看不清、公式框特别大”**：
   - 含中文说明、或较长的公式不再拆成左右两栏，统一按整段可换行文本排版，永远不会错位；
   - 只有“纯数学、较短”的公式才做 `左 = 右` 分栏，且只有短分数才做上下堆叠（如 `a/(1-q)`、`(-b±√(b^2-4ac))/(2a)`），长分数保持行内；
   - 自动整理运算符间距：`a+b → a + b`、`x-1 → x - 1`，指数中的 `e^-x`、`10^-11` 不受影响；
   - 统一衬线字体、1.55 倍行高、字距与左对齐。
   - 顺手把“伯努利方程”等公式里的中文说明从表达式移到注解，公式框不再被撑大。
2. **长图转 PDF 修复 “Software rendering doesn't support hardware bitmaps”**：
   - Android 9+ 的 `ImageDecoder` 默认会返回硬件位图（HARDWARE），软件 PDF 画布无法绘制；现在统一强制 `ALLOCATOR_SOFTWARE`，并在解码后做二次转换，保证所有图片处理工具拿到的都是软件位图；
   - 长图转 PDF 里再补一层保险：遇到 HARDWARE 位图自动转成 ARGB_8888。

## 技术栈

- Kotlin 2.0.21 + Jetpack Compose（Material 3）
- 单 Activity + Navigation Compose
- 本地存储：SharedPreferences + JSON
- 二维码：ZXing core（本地生成）
- 视频：Media3 Transformer（本地转码/变速）+ 系统 MediaExtractor/Muxer

> 第一次构建需要联网下载依赖。

1. 用 Android Studio 打开本目录（建议使用已安装的 `D:\Program Files\Android\Android Studio`）。

  node _build_vocab.js   # 输出 app/src/main/assets/vocab_bulk.jsonl

  `FormulaBooksCalculus.kt`（高数上/下）、`FormulaBooksAlgebra.kt`（线代、概率统计）、

## 已知限制

- Word 转 PDF：本地解析 .docx 的段落与表格文字后按 A4 重新排版，图片、公式、分栏等复杂版式不会原样保留；旧版 .doc 需先另存为 .docx。
- PPT 转图片：只提取每页文字并重新排版，图片、图表、SmartArt、动画不会保留；要做到与 PowerPoint 完全一致需要 Office 渲染引擎。
- 视频：输出为 MP4(H.264/H.265 + AAC) 或仅音频 M4A；AVI 及部分特殊编码输入可能失败；**倒放**系统 API 暂不支持，需要引入 FFmpeg 才能实现。
- TIFF：本应用可输出未压缩 TIFF，但 Android 系统无法解码 TIFF 输入，需先用其他应用转成常见格式。
- 词表：考纲词表依据 ECDICT 标签整理，采用“官方规模 + 含基础词补全”两种模式；如与最新版考纲有出入，可自行导入自定义词库补充。在线释义/例句依赖第三方公开服务（dictionaryapi.dev），可能因网络或服务变动不可用，离线精讲内容不受影响。
